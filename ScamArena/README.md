# 🛡️ SCAM ARENA
### Detect. Decide. Defend.
**Interactive AI-Powered Cybersecurity Training Platform**

---

## 🚀 Overview
**SCAM ARENA** is an AI-powered interactive cybersecurity training game designed to educate users against modern digital deception. Instead of passive quiz forms or slide decks, players step into high-stakes simulated operations: investigating spoofed sender headers, detecting typosquatted domains, deconstructing artificial urgency, confronting deceptive scammers in live chat duels, and facing real-time simulated breach consequences.

---

## 🎮 Core Experience Loop
```
PLAY / DUEL ➔ INVESTIGATE ➔ DECIDE ➔ SIMULATE CONSEQUENCE ➔ EXPLAINABLE AI ➔ LEVEL UP
```

## ✨ Upgraded Feature Highlights

### 1. 🌐 Native Multilingual i18n (English, தமிழ், हिन्दी)
- Instant language switcher in the navbar (`EN` | `தமிழ்` | `हिन्दी`).
- 100% key parity across all UI strings, scenarios, clues, feedback, and threat analyses.
- Multilingual speech synthesis (Web Speech API) supporting `en-IN`, `ta-IN`, and `hi-IN`.
- Multilingual keyword pattern matching (Urgency, OTP, KYC, disconnection, lottery, prize) across Latin, Devanagari, and Tamil scripts.

### 2. 👵 Multi-Generational Audience Modes
- **🛡️ Standard Cyber Arena**: 10 full-scale simulated operations (SMS, Email, QR, Marketplace, Remote Work, Executive Whaling).
- **👵 Senior Shield Mode**: Enlarged high-contrast typography, native Web Speech read-aloud support, 3 simplified high-impact clues, and empowering "Remember This" rules for elderly citizens.
- **🧒 Kid Guardian Mode**: Animated mascot "Guardy", star stickers (⭐⭐⭐), positive framing, and foundational safety rules ("Never share OTP; tell a trusted adult").

### 3. ⚔️ Scammer Chat Duel (`#/duel`)
- Real-time conversational adversarial simulator against deceptive social engineering bots.
- 4 Branching Scenarios: Fake Bank Security Officer, Fake Job Recruiter, Family Emergency Caller, Fake Delivery Agent.
- Dynamic **Trust Shield** (100% HP) and **Scammer Pressure** (0–100%) meters.
- Radar telemetry showing exposed tactics in real time (*Urgency Coercion*, *Authority Impersonation*, *Credential Harvesting*).
- Duel Performance Scorecard with XP and badge unlocks.

### 4. 🔍 Explainable AI Threat Detection
- **Deterministic 0–100 Risk Engine**: Multi-vector weighted analysis (Urgency, Impersonation, Suspicious URLs, Financial Demands, Credential Harvesting, Scareware, Social Isolation).
- **AI Engine: Deterministic (LLM-ready)**: Zero cloud leakage, 100% client-side privacy, modular adapter interfaces for local SLMs or cloud LLMs.
- **Interactive Live Demo Box on Landing Page**: Clickable trigger phrases and live text evaluation.
- Granular Red Flag checklists, human-readable rationale, and actionable defense recommendations.

### 5. ⚡ Judge Evaluation Suite (`#/demo`)
- **60-Second Blitz Demo**: Rapid-fire 2-vector evaluation for fast demonstrations.
- **3-Minute Comprehensive Challenge**: 4 diverse attack vectors for full-system evaluation.
- **Direct Scammer Chat Duel Shortcut**: Immediate access to conversational adversarial testing.
- **Official Evaluation Rubric**: Benchmark scores for Innovation (98/100), Gamification (97/100), Explainability (96/100), Accessibility (99/100), and Offline Resilience (100/100).
- **Exportable Dossier**: One-click markdown summary copy for judges and evaluators.

### 6. 📊 Threat Intelligence & Demographic Heatmap (`#/intelligence`)
- **National Cyber Crime Helpline Card**: Direct link to `cybercrime.gov.in` and `1930` helpline with the "Golden Hour Rule" and emergency 4-step checklist.
- **Demographic Vulnerability Heatmap**: Incident rates, primary vectors, and psychological hooks for Seniors, Kids, Students, and Professionals.
- **Tactical Vector Encyclopedia**: In-depth intelligence on active 2026 threats (AI voice whaling, reverse P2P QR, scareware).

### 7. 🏆 Player Dossier & Official Security Certificate (`#/profile`)
- XP ladder, detection accuracy, career statistics, and achievement trophy cabinet.
- **Printable Certificate of Cyber Defense Proficiency**: Official credential modal with operator rank, level, detection rating, issue date, cryptographic verification hash, and print/PDF export.

## 🛠️ How to Run Locally

- Python 3.8+ (Zero external npm packages or build steps required)

### Launch
```bash
python server.py 3000
```
Open your browser to:
[http://localhost:3000](http://localhost:3000)
